# MISUKI PAINT EXECUTION PROTOCOL V3

This file is machine-first. It exists to prevent one-pass procedural drawing.

1. Build guides and head proportions.
2. Validate head curvature. A flat/polygon roof fails.
3. Place horn centerlines and validate roots.
4. Block hair as large filled masses. Do not draw dozens of parallel strands.
5. Place facial features from guides and validate eye/face ratios.
6. Build neck, choker, shoulders and a curved gothic torso silhouette.
7. Expand horn axes into tapered volumes and add sparse ridge cues.
8. Build 3-7 major fringe locks as filled tapered shapes, then only a few internal hair lines.
9. Commit black masses while protecting facial negative space.
10. Add gray only for form separation.
11. Add sparse gothic details.
12. Check thumbnail identity.
13. Run structural score. If below 82, repair before export.
14. Export only the approved render.

Repair order: silhouette > horns > hair > face > outfit > tone > detail.
