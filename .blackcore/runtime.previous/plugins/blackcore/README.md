# BLACKCORE Plugin (MCP) — Phase 1

Plugin-ready adapter for the BLACKCORE Termux/Linux agent.

```bash
./setup.sh
./start-http.sh
```

Local endpoint: `http://127.0.0.1:3000/mcp`

This Phase 1 exposes focused, isolated project tools for plugin testing while keeping the normal BLACKCORE terminal application intact. See `docs/PHASE-1-README.md` and `docs/SUBMISSION-CHECKLIST.md` before public deployment.
