# BLACKCORE roadmap

## 3.0 foundation

- Multimodal image input and interactive browser sessions.
- Reproducible dependencies and installation profiles.
- Stronger workspace path enforcement and public project governance.

## Next

- Optional OS-level sandbox adapters for supported Linux systems, with a Termux-safe fallback.
- Language-server and AST diagnostics for high-signal code navigation.
- Isolated subagent worktrees with explicit concurrency and cost budgets.
- Measured provider/model cost budgets and exportable session traces.
- Mobile companion for monitoring and approving a BLACKCORE runtime; API keys remain on the runtime host.

The roadmap describes intended work, not shipped capabilities. Releases and tests are the source of truth.
