Tests ran with an isolated writable `HOME` and `BLACKCORE_HOME`. The first sandbox run intentionally demonstrated that a denied operating-system home cannot be bypassed; the isolated run then passed 162/162. This is the expected security boundary. Pure `version` and shell-completion commands were hardened to work without initializing a writable BLACKCORE home.

## 3.2.0-specific evidence

- Permission inspector tested in simulated Termux with accessible and missing shared storage, available and missing Termux:API commands, desktop Linux, and a project under Android shared storage.
- `blackcore permissions` and `blackcore doctor --full` run without an AI key.
- The installer exposes `--setup-storage`, reports long package progress and preserves Android's visible permission decision.
- Dependency-free HTML, Flutter and PHP/Composer projects are detected with deterministic verification plans.
- Python ecosystem commands select uv, Poetry, Pipenv or pip from lock/project evidence.
- The actual creative-lab JavaScript ran for 180 simulated animation frames at approximately 60 FPS and passed mouse, touch, keyboard, pause, heart and game-state assertions.
- The creative lab is valid static content and its assets were served successfully over local HTTP.

## Honest boundaries

- No installed Chromium executable was available in the release container. The browser download endpoint returned an incomplete archive, so no claim of live screenshot inspection is made for this release. Static, runtime-simulation, local-HTTP and accessibility-contract tests passed.
- No physical Android device or complete Android SDK was attached. The Expo/EAS APK source contract, Gradle/ADB command adapters and Android project detection were tested, but a real APK installation was not.
- Vercel, Netlify, Supabase, Resend, Expo/EAS and GitHub adapters passed deterministic CLI fixtures and safety confirmations. No production account operation was performed.
- Android itself controls Files and media, camera, location and notification permissions. BLACKCORE diagnoses and explains them; it cannot silently grant them.
