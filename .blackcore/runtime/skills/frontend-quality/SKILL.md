# Frontend Quality

Check:
- mobile and narrow-width behavior;
- keyboard/focus accessibility;
- loading/error/empty states;
- semantic HTML and labels;
- hydration/client-server boundaries;
- image sizing and performance;
- route errors and 404s;
- production build warnings;
- browser console/runtime errors.

Prefer using the project's existing component system instead of introducing a second design system.
