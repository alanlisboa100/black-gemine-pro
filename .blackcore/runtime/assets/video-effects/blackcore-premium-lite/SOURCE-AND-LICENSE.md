# BLACKCORE Premium Lite

The 12 source textures in `overlays/` were downloaded from:

https://github.com/RPicster/Godot-particle-and-vfx-textures

The upstream project states that the project and textures are released under
CC0, with no attribution required. The unmodified CC0 text is included as
`LICENSE-CC0-1.0.txt`.

BLACKCORE uses these textures as local grayscale compositing layers. The 24
named color/motion variants in `pack.json` are BLACKCORE presets, not separate
upstream files. No After Effects, Premiere or proprietary project files are
required.
